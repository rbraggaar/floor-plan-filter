about=Floor Navigator provides two approaches for displaying floor-specific data in QGIS:
    Attribute Filter: Dynamically applies a subset query on vector layers using a standardised 'floor_level' column.
    Layer Group Filter: Toggles visibility of layers within registered layer tree groups using a _[FLOOR_ID] naming convention.
    Floors can be grouped into combined Levels that activate together.
    Developed with AI assistance (Claude, Anthropic).
